SocraMetry — AI に答えを出させるのではなく、AI に問いを出させる。
セキュリティ説明
2026-08-14 版
v0.1 実装時点

SocraMetry はエラーログを貼り付けて使う製品です。エラーログには API キーや接続文字列が日常的に混入するため、「混入する前提」でシステム側が守る設計にしています。 本書は、何をしていて、何を保証していないかをまとめたものです。

1. この製品固有のリスクを直視する

#リスクなぜ避けられないか
R1入力に認証情報が混入する貼り付けるのはエラーログ。ログには API キー・トークン・接続文字列が日常的に含まれる
R2入力が外部の LLM プロバイダに送られる診断のためにエラーテキストを LLM に渡す必要がある

R1 は「ユーザーが気をつける」では解決しません。本人が気づかずに貼り付けるから混入するのであり、 システム側で除去する以外に方法がない——これが設計の出発点です。

2. 秘匿情報の自動マスキング(R1 への対策)

データストアに保存する前・LLM に送る前に、認証情報を自動でマスクします。 クライアントとサーバの二段構成で、同じマスキング関数を両側で実行します。

ブラウザ ─┬─ ① 貼り付けた瞬間にマスク ──▶ ② マスク結果をプレビュー表示 │ (送信前に自分の目で確認できる) └─ マスク済みテキストのみ送信 │ サーバ ─────── ③ マスキングを再実行(ここが正・冪等) ├──▶ データストアへ保存 └──▶ LLM へ送信

クライアント側のマスクは UX のためであり、保証はサーバ側の再実行が担います。 同一の関数を両側で使うため、プレビューで見た内容と実際に送られる内容がずれません。 生のテキストはブラウザから外に出ません。

未登録の顧客名などの固有名詞は、正規表現では機械的に検出できません。 そのためマスク結果を送信前にプレビューで表示し、利用者自身が確認・修正できる導線にしています。 「マスキングしているから安全」ではなく、何をしていて何を保証していないかを明示する方針です。

3. LLM プロバイダへのデータの扱い(R2 への対策)

項目方針
学習への利用ゲートウェイ(OrcaRouter)側で入力を学習に使わせない設定を確認し、明記する
送信内容マスキング済みのエラーテキスト・コード断片のみ。メールアドレスや氏名は送らない
利用者への説明外部 LLM に送られること・マスキングの内容と限界を UI に明記。送信内容は事前にプレビューで確認できる

4. API キーと認証の守り方

API キーをブラウザに出さない

✗ してはいけない構成 ブラウザ ──[APIキー]──▶ LLM ゲートウェイ ↑ DevTools で誰でも見える ✓ SocraMetry ブラウザ ──▶ サーバ関数 ──[APIキー]──▶ LLM ゲートウェイ ↑ 実行環境の環境変数にのみ存在

キーはクラウド実行環境の環境変数にのみ置き、リポジトリにも CI にも置きません。 CI が知るシークレットをデプロイ用の 1 つに絞ることで、漏洩経路そのものを減らしています。

認証・アクセス制御(v0.1)

項目実装
登録招待コード必須。公開 URL に無制限のサインアップを置かない(コスト流出防止を兼ねる)
パスワードソルト付き scrypt でハッシュ化して保存(平文保存しない)
セッションJWT を HttpOnly / Secure / SameSite=Lax の Cookie に格納。有効期限 24 時間
他人のデータデータストアのキーに所有者 ID を含める構造のため、他人のセッション ID を渡しても「存在しない」としか返らない
入力検証サーバ側で必ず検証(文字数上限・許可リスト・ID 形式)。フロントの検証は UX のためで、防御はサーバが担う

5. ログに個人情報・秘匿情報を残さない

記録する記録しない
セッション ID(個人を特定しない)・役割・モデル名・トークン数・レイテンシ・推定コスト・エラーコード エラーテキストの本文・コード断片・メールアドレス・氏名・パスワード・例外に含まれる入力値

ログの目的は運用とコスト把握であり、入力内容の再現ではありません。 本番環境では入力の「長さ」だけを記録し、本文は残しません。 利用者は自分のセッションデータを削除できます。

6. 濫用への防御

層実装
レート制限セッション作成 10 回/時/ユーザー。LLM コストの流出を防ぐ
トークン上限1 セッション 80,000 トークンで打ち切り。暴走的な生成を止める
冪等性同じ設問への二重回答は同じ結果を返す。API を直接叩かれても LLM を連打させられない
XSSLLM の出力は信頼できない入力として扱い、HTML として描画しない
通信すべて HTTPS(実行環境が TLS を終端)
